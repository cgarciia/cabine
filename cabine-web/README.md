# cabine-web

SPA da Cabine (totem + telas de operador). Fala com `cabine-core` via HTTP e WebSocket.

Mapa de pastas, rotas e regras: **[`.cursor/specs/09-frontend.md`](../.cursor/specs/09-frontend.md)** (índice em [`.cursor/specs/README.md`](../.cursor/specs/README.md)).

```bash
npm install
npm run dev
```

Vite em `https://127.0.0.1:5173` (certificado autoassinado; proxy para a API em `:8000`).
